# Requerimientos Funcionales

## Núcleo

| ID | Requerimiento |
|----|---------------|
| RQF-001 | El sistema debe ejecutar sobre Pi como runtime principal. |
| RQF-002 | El sistema debe contar con un agente orquestador principal de seguridad. |
| RQF-003 | El orquestador debe clasificar cada caso en dominio SOC, Blue Team o Red Team. |
| RQF-004 | El sistema debe soportar perfiles `soc`, `blue-team` y `red-team`. |
| RQF-005 | El sistema debe integrarse con Engram para persistir contexto útil entre sesiones. |

## Evidencia y control

| ID | Requerimiento |
|----|---------------|
| RQF-006 | El sistema debe separar observación, interpretación y recomendación. |
| RQF-007 | El sistema debe asociar conclusiones relevantes con evidencia trazable. |
| RQF-008 | El sistema debe requerir aprobación humana para acciones sensibles. |
| RQF-009 | El sistema debe bloquear acciones fuera de alcance o destructivas por defecto. |
