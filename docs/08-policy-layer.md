# Policy Layer

## Objetivo
Definir qué acciones están permitidas, cuáles requieren aprobación humana y cuáles deben bloquearse siempre.

## Modelo base

| Nivel | Significado |
|------|-------------|
| Permitido | puede ejecutarse sin fricción extra |
| Requiere aprobación | necesita confirmación humana explícita |
| Bloqueado | no debe ejecutarse desde el agente |

## Regla central
En seguridad, el control humano no es opcional para acciones sensibles.

## Próximo paso
Complementar esto con una evidence layer común a todos los dominios.
